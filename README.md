
#ROCK PAPER SCISSORS TERMINAL GAME.

This is a terminal game of rock paper scissors crated with plain Vanilla Javascript and HTML as part of the Odin Project assignments. This game works in the console.


##ABOUT

The game is a game of choices, rock , paper and scissors. After each round, the user selects their choice be it rock, paper or scissors and the computer randomly selects its choice. A rock beats scissors, scissors beats paper and paper beats rock. It is a game of five rounds and the final score is displayed to the user>

##HOW TO PLAY

1. Fork this repository and clone it to you local machine
2. Open the repo in your File Explorer
3. Run or double click on the index.html file to open the page.
4. Right click on the page and select 'Inspect' from the options to see the scores after a game of five rounds.
